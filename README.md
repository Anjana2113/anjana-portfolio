## 🚀 How to Deploy to Cloud (Free in 2 Minutes)

### Option 1: Vercel (Recommended)
1. Push this folder to your GitHub account under a new repository (e.g., `portfolio`):
   ```bash
   cd C:\Users\ANJANA\.gemini\antigravity\scratch\portfolio
   git init
   git add .
   git commit -m "feat: complete personalized portfolio"
   git branch -M main
   git remote add origin https://github.com/Anjana2113/portfolio.git
   git push -u origin main
   ```
2. Go to [vercel.com](https://vercel.com) and log in with your GitHub account.
3. Click **Add New...** $\rightarrow$ **Project**.
4. Select your `portfolio` repository and click **Deploy**.
5. Your live URL will be ready instantly: `https://portfolio-anjana.vercel.app`.

### Option 2: GitHub Pages
1. In your GitHub repo `Anjana2113/portfolio`, go to **Settings** $\rightarrow$ **Pages**.
2. Under **Build and deployment** $\rightarrow$ **Branch**, select `main` and `/ (root)` and click **Save**.
3. Your site will be live at: `https://anjana2113.github.io/portfolio/`.
